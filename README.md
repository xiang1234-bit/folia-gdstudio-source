# Folia 音源模组：GD 音乐台 (`gdstudio-music`)

将 [GD 音乐台](https://music.gdstudio.xyz/) 公开音乐接口（`https://music-api.gdstudio.xyz/api.php`）封装为符合 **Folia / Folium 2** 规范的可导入 `.zip` 音源模组。

## 安装 / 升级步骤

1. 打开 **Folia**，进入 **「设置 → 模组」**，开启 **「模组系统」** 与 **「社区模组」**。
2. 在 **「设置 → 音源」** 点击 **「从 zip 安装音源模组 → 选择 zip」**，选择 `gdstudio-music-1.2.0.zip`（同 ID 覆盖安装即可无缝升级，已导入的歌单数据会自动保留）。
3. 升级或首次安装后，由于文件指纹变化，请在 **「设置 → 模组」** 重新启用 **「GD 音乐台音源」** 并确认信任提示。

## 导入 GD 音乐台歌单的 4 种方式

切换到 **「GD 音乐台」** 音源后，你的歌单会直接显示在首页 **「歌单」** 页签（同时也可在 **「探索」** 页签浏览热门榜单与已导入歌单；导入新歌单后，点击切换器登录窗口里的「同步」或「探索」页右上角「刷新」即可立即刷新列表）：

1. **内置热门榜单（无需配置）**：自动展示热歌榜、新歌榜、飙升榜、原创榜、欧美热歌榜、ACG 榜、电音榜、抖音排行榜，点开即可播放或转存为 Folia 歌单。
2. **按网易云用户 UID 导入（与 GD 音乐台网页端一致）**：
   - 在命令面板（`Ctrl+K`）运行 **「GD 音乐台：导入用户歌单（网易云 UID）」**，或在 **「GD 音乐台设置」** 中填入 **「同步歌单的网易云用户 UID」**。
   - 请确认该网易云账号的歌单隐私已设为「所有人可见」。
3. **按歌单 ID / 链接导入**：
   - 运行命令 **「GD 音乐台：导入歌单（ID / 链接）」**，或在 **「GD 音乐台设置」** 的 **「歌单 ID / 链接」** 中填入单个或多个歌单 ID / 链接。
4. **从 GD 音乐台网页端导出的本地 JSON 导入**：
   - 在浏览器打开 `https://music.gdstudio.xyz/`，按 `F12` 切换到 **Console（控制台）**，执行下面一行代码下载本地歌单备份文件 `gd_music_backup.json`：
     ```js
     (() => { const a = document.createElement('a'); a.href = 'data:application/json;charset=utf-8,' + encodeURIComponent(JSON.stringify(localStorage)); a.download = 'gd_music_backup.json'; a.click(); })();
     ```
   - 回到 Folia，在命令面板或模组面板运行 **「GD 音乐台：从 JSON 文件导入本地歌单…」**，选择该 JSON 文件即可导入。

## 声明与注意事项

- 数据与音频接口均来自 **GD 音乐台 (`https://music.gdstudio.xyz/`)**，仅供个人学习与研究使用，请勿用于商业用途。
- 公开接口约有 **5 分钟 50 次请求** 频率限制；模组已对歌单、歌词和封面做缓存，若频繁触发限流可稍候再试，或在设置中关闭「按需加载专辑封面」。
